# 从仓库取得教师，并接入自己的训练

本仓库交付的是第五批最终六套**冻结的接口修复教师库**及逐场景事后选择。它没有预先规定学生采用 SFT、哪些层解冻、LoRA 或外挂修复器。你已有的 RL Base 和数据仍由当地平台提供。

## 1. 克隆仓库

```bash
git clone https://github.com/sjc786526-coder/-recogdrive-representation-teacher-2.git
cd -- -recogdrive-representation-teacher-2
```

先读根目录 `README.md`，然后在浏览器直接打开 `reports/interface_representation_repair.html` 和 `reports/representation_distillation_diagnosis.html`。HTML 已内嵌图片，无需运行网页服务器。GitHub 文件页显示源码时，在本地浏览器打开即可。

仓库是公开仓库，拉取不需要令牌；若后续改为私有，由仓库所有者在 Settings → Collaborators and teams 添加你的 GitHub 用户名，再按你当地的 GitHub 登录方式克隆。

## 2. 检查环境与资产身份

使用你现有的 ReCogDrive/NAVSIM 环境，不要为了本包把当地加速卡的 Torch 替换成不兼容版本。`requirements-inference.txt` 记录原版本，不是要求无条件覆盖安装。只使用接口 API 时主要需要 NumPy 和 PyTorch；端到端图像推理及重新评分还需要原 ReCogDrive/NAVSIM 的完整依赖。

```bash
cp configs/paths.example.json paths.local.json
# 编辑路径：checkpoint、vlm、maps、navtrain/navtest 的 logs、sensor、metric。
# 若有与原实验逐字节一致的 VLM 特征缓存，另填 navtrain_features / navtest_features。
python -B check_assets.py --paths paths.local.json
python -B verify_package.py
```

`verify_package.py` 不加载大模型，不访问数据集，不重新评分。它验证文件 SHA、24 份真实运行记录中的全部专家请求和限幅、完整 12 个“库×数据集”的选择及均分。`reference/LOCAL_VALIDATION.json` 说明交付前实际做过哪些检查，异机完整运行仍以你的验收为准。

必须匹配的 RL checkpoint SHA256：

```text
23fb949b10387efeff87e093703d5faf41b61b9e5ead16d4076661e3c7c08a20
```

口头称为 RayDrive/ReCogDrive 不是模型身份校验。配套 VLM 的指纹也保存在 `configs/repair_final_baseline.json`。若文件 SHA 不同，先核对是否只是 checkpoint 容器重新序列化；在确认活跃 tensor 完全一致前，不把旧选择直接当作当地最优。

目录示例：`navtrain_logs` 下应有 `trainval/<log>.pkl`；`navtrain_sensor` 下应有 `trainval/<log>/...`；`navtest_logs/sensor` 对应 `test` 子目录；metric 根下为 `<log>/unknown/<token>/metric_cache.pkl`。场景清单中的相对路径是准确来源，不依赖本地 `/mnt/...` 布局。

## 3. 先选择一套教师库

如果先做一个起点，`D_C8_double` 是本轮已测六套中完整训练和测试的离线上限最高者。这里的优势依赖事后选择；不要把 96.2389 当成普通单模型已实现的成绩。

另五套全部保留，修改 `--library` 即可独立使用。每套有自己的选择表，不能把某套的选择编号应用到另一套。`choice=0` 表示 Base；`1..K` 与该库 JSON 中 `experts` 顺序一致，不等于聚类标签。

## 4. 先重放两例，再批量导出

先从原始观测生成接口与轨迹：

```bash
CUDA_VISIBLE_DEVICES=0 python -B export_teacher.py \
  --paths paths.local.json --out outputs/smoke_D_C8_double \
  --population train --library D_C8_double --source raw \
  --limit 2 --save-full-interface --score
```

一个场景先运行冻结 Base 得到原生 `feature_encoder` 输出，再应用已保存的一个专家；五组噪声均使用这一修复。脚本不会在当地重新选专家、不会强制只修 `<70` 样本。

每例输出 `TARGETS.npz` 和最后原子写入的 `COMPLETE.json`。检查：接口/轨迹为有限值、padding 未改、实际 RMS 符合限幅、Base 和教师实际重新评分与历史值的差距。`--score` 才会重新计算当地分数；元数据中的 `saved_selection` 始终是历史分数，不冒充新评分。

如果有原实验一致的缓存，`--source cached` 可跳过 VLM 前向。仍从原始观测恢复输入 token/mask，并检查缓存 SHA 和自车状态/导航/历史信息一致。仅有模型和原始数据、不带缓存时使用 `raw`。不能把另一套 prompt 或另一模型生成的缓存混进来。

跨硬件可能有浮点差异。固定种子不等于不同 GPU/驱动/Torch 必然逐位相同；先对照 `reference/GOLDEN.json` 中有记录的场景。原生动作头必须保持 FP32、autocast 关闭、batch size=1、TF32 关闭。调大 batch 或更换精度属于新的执行协议，应另行验收。

## 5. 不必保存几百 GB 的完整接口

默认导出每场景实际修复量、mask、token、Base/教师 S0–S4 轨迹和选择信息；加 `--save-full-interface` 才同时保存完整 Base/教师接口。接口典型形状是 `[2800,384]` FP32，一个就约 4.3 MB，全训练集完整双份接口未压缩约 0.74 TB，实际长度与压缩率会变化。

训练时可用冻结 Base 在线生成接口，应用库中的冻结算子得到 `detach()` 后的教师目标。也可离线只存实际 shift，再用同一冻结 Base 的原生接口重建：

```text
teacher[token] = Base[token] + applied_shift[role(token)]
```

必须保持 FP32 原生加法和有效 token/mask；这不是用平均384维向量替换所有 token。当前两种 role 的修复向量相同，但 padding 保持原值。限幅后实际 shift 才是要保存的值，不能误用限幅前 requested shift。

## 6. 接入你自己的训练器

```python
from interface_teacher import Library, DecisionTable
from examples_training import build_teacher_target, representation_loss

library = Library("D_C8_double")
decisions = DecisionTable("D_C8_double", "train")

# 从一份固定的 RL Base 生成 post；不要用正在更新的学生生成教师。
teacher_post = build_teacher_target(
    frozen_Base_post, image_mask, valid_text_mask, token, library, decisions
)
loss_H = representation_loss(student_post, teacher_post, image_mask, valid_text_mask)
# 你自行决定是否联合轨迹损失、解冻模块/LoRA/修复器、学习率及数据采样。
```

完整接口监督可回传到 VLM、投影或动作头；只有实际参与 loss 计算图的可训练模块才会更新。若训练 VLM，不能仅从缓存的末层 hidden 开始而仍宣称训练到了上游 VLM。

若外挂网络只预测一个共享384维修正向量，可使用实际 shift 作为目标；不要求网络重新预测每个 token 的完整 hidden。Base 的零干预样本是明确的零修正目标。具体训练方案仍需独立验证，当前交付包没有替你证明哪种最有效。

只用 `train` 选择表生成训练目标。`manifests/validation.csv.gz` 另列原会话留出17,475例/32会话，不带这六库的事后教师选择；用于验证和选权重。测试12,146例的选择表用于复现离线上限，API/CLI需要显式允许，不用于训练。

## 7. 可配置分片与接续

```bash
# 例如8张卡，每个进程只看到一张卡；无32卡或DLC依赖。
for rank in $(seq 0 7); do
  CUDA_VISIBLE_DEVICES=$rank python -B export_teacher.py \
    --paths paths.local.json --out outputs/train_D_C8_double \
    --population train --library D_C8_double --source raw \
    --rank "$rank" --world-size 8 \
    > "outputs_rank${rank}.log" 2>&1 &
done
wait
```

相同输出目录可在确认旧进程退出后接续；已完成场景只有协议和文件 SHA 均匹配才跳过。不要同时启动两个相同 rank/world-size 组合写同一批场景；本入口提供静态分片，不是共享队列调度器。多机也可以采用相同 world-size 与不重叠 rank。你的调度平台可以封装这些独立任务。

`reference/GOLDEN.json` 为少量实际记录，`decisions/*/*/pdms_*.npz` 保存所有候选五噪声平均值，可独立验证选择；未搬运每个候选的全量逐噪声轨迹、完整隐藏状态或搜索中间缓存。复现冻结教师不需要重跑子空间/聚类/算子搜索。
