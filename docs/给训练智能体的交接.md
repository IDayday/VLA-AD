# 给接收方训练智能体的交接

你接手的是冻结离线教师资产，不需要重跑原研究的子空间、聚类和专家选择。先读根README、操作指南和两份HTML；以本仓库的实际六库配置、决策表和SHA为准。

## 你可直接复用的接口

`Library("D_C8_double")` + `DecisionTable("D_C8_double","train")`。

将**冻结RL Base**原生投影输出`[1,L,384]`、image/有效text masks和token传给`selected_target`，即得同场景完整教师接口。你可自行决定学生训练哪些层/模块、用哪些loss和数据权重；本包没有开启任何训练或预先锁定你的方案。

教师目标与动作噪声独立。同一场景的目标接口和专家在S0–S4不变；如果蒸馏轨迹，五条目标轨迹分别对应五组既定噪声，不能随便平均后称为原教师。

## 必须先通过的小检查

1. `verify_package.py`通过；模型权重指纹一致。
2. 当地先运行两例原始输入或已匹配缓存重放，核对Base/教师接口、实际修复量、padding及S0–S4轨迹/真实评分；不要只看进程不报错。
3. 正确地将教师与学生分开。全参或LoRA更新学生时，不能让教师Base跟着变化；禁止以学生自己的漂移接口重新算原冻结专家目标。
4. 训练前做正控制：零干预在初始化时应接近零损失；选少量非零目标检查可拟合性、梯度路径与loss尺度。此前已经出现过原生数值路径和优化配置使“参数在更新但目标更远”的情况。
5. 分别报告监督拟合、真实PDMS、原有样本的收益/损失。不把表征MSE降低当作PDMS必然改善，也不把Oracle上限当作单模型成绩。

## 数据身份

训练侧实际85,813例/130会话，验证侧17,475例/32会话，二者会话隔离；独立测试12,146例。用token连接，不用CSV行号充当global index。六库均有训练与测试事后选择；测试标签仅用于原上限复现，不混入训练。

这些训练选择属于最终训练侧重拟合专家库产生的in-sample离线教师，不伪称交叉验证OOF教师。若你另做OOF教师或新验证协议，应新命名与记录，不能覆盖当前冻结资产。

## 研究上已经知道什么

接口干预库能提供很高离线候选上限；错误强制应用专家时，总体会受损。因此参数吸收必须同时学到选择性改变与保持。已有两轮蒸馏、第五批小样本/数值路径/目标可拟合性/修复器诊断，有明显正反例，完整见诊断HTML。不要把这些证据概括成“所有教师都不可学”或“已经证明某一训练方案可泛化”。

此次交付不替你决定是否继续相同监督；你的新增实验应在你自己的输出目录保存参数、配置、数据身份和真实评分，保留本包不变。
