# 固定允许资源上的完整 GT 与 D48 教师流程

此目录保留原1,850候选范围的实现与迁移历史。当前正式本机重筛范围和生产源码见相邻 `native_candidates_20261027/`：按完整Train的Base S0<70得到1,689候选，不固定原PPU候选数。

原 GT 配对搜索完整保留，包括通过 GT 轨迹误差、冻结动作网络与原生去噪链对接口修复变量反传梯度。完成所有原定阶段和 1,850 个原候选场景的优化记录导出后，才拟合本地 D48／先聚类 K8／专家并校准、增强、冻结和全量评分。子空间秩足够不代表缩短搜索的效果足够；早期缩短方案及其产物不进入正式教师。

数学与采样实现仍使用上一级 `code/` 的冻结源码。此处的 `fullflow_teacher_owner.py`、`permanent_dispatch.py` 只接入固定允许资源、按设备分配进程数量、处理本机启动及验证完整搜索证据。`round1_prepare_and_run_permanent.py` 接续同一正式教师，完成目标、定标、真正多卡/反向/恢复核验及八个完整学生实验。

仅使用固定允许的 vla-zt、vlawm-tsinghua-zt/zt3/zt4/zt5；实际派发还需核对当前任务授权、UUID、余量及其它作业。zt6、rl-zt2、tsinghua-zt2、vlawm-zt 的临时授权已撤回，不再接受新任务、重试或压力填充。资源文件显式保存主机和 GPU 身份，不能把本机路径或资源分配当作通用默认值。

学生每 run 使用2卡或4卡均保持 global batch64、microbatch1、40 epochs、53,640次更新；所有八个run使用同一资源布局。恢复须保持原 world size，不能将不同卡数的检查点视为精确续训。完整资格检查必须绑定实际卡数与累积布局。

原始搜索完成由 `SEARCH_COMPLETE.json`、十五阶段验收摘要及SHA、最终队列关闭、1,850候选记录实际导出和全部登记GPU进程退出0共同证明；后台启动、部分配对或短版cut均不满足条件。Train/Test就绪后即可接续学生准备，Validation教师诊断独立推进。

等待结果按实测吞吐估算下次读取时间，并加入尾任务缓冲。助手不进行高频结果轮询；计算队列、检查点和阶段调度仍正常执行。

候选记录数与成功配对数分开报告；原清单1,850个候选的全部记录完整，并不表示本机得到1,850个成功训练配对。
