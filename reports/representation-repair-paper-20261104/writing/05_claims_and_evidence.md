# 论文主张与证据强度

| 主张 | 已有证据 | 表述边界 |
| --- | --- | --- |
| 普通输入下可改善冻结策略 | RL/v1三seed 90.4793→92.4074；单前视 | 系统保留运行时专家与选择模块，驾驶参数冻结 |
| 同场景反事实具有行为价值 | 实际原G轨迹评分、高质量端点与跨噪声检验 | 特权构造，不是唯一正确表征 |
| 共享方向有普通收益 | R6−D48内随机方向：+0.3254，描述性会话区间为正 | 随机控制也在已学D48中，不能扩成“任意随机空间无效” |
| 条件算子有额外价值 | 主库−同簇全固定：+0.1112，会话区间为正 | 当前两个MLP替换对照，非所有条件模型的普遍结论 |
| 配对与聚类有作用 | Oracle改善；普通均值约+0.19 | 普通TEST会话区间仍含零，未校正多重比较 |
| 方法可完整迁移 | IL自己的配对、专家、A/FH；ePDMS +4.2775 | 改基模收益不计作修复贡献；不等于跨架构验证 |
| 两阶段有迁移收益 | 冻结代表26.3478→38.8995 | 单代表五动作噪声；没有两阶段训练/选模 |
| 在线开销可量化 | P50 483.85→549.93ms，PPU-ZW810E | 参考实现，不能声称车端实时或没有额外计算 |
| 合成RL并未保证提分 | 78个TUNE点；最终Base TEST −0.0076 | 无纯真实等预算控制；不否定所有合成数据或RL |

三训练seed SD、会话bootstrap与动作噪声分别描述不同不确定性。历史TEST被研究反复观察，不称全新盲测。详见[结果材料](03_results_and_ablations.md)及[来源索引](../sources/source_index.html)。
