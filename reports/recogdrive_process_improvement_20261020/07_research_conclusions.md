## 当前能够成立的结论

完整普通 OPD 已在 74,885 场景上完成三种子、两轮真实训练。锁定的一轮配方在完整 dev 上迁移了部分教师平均能力：PDMS 0.943662，相对 IL 的 G=0.028475，95% CI [0.013934,0.044534]；仍比原 RL/T0 低 0.005965，CI [-0.010216,-0.003469]。直接复制 T0 在同构学生中数值完全一致、无需新增训练，是不能省略的强对照。当前不支持把蒸馏本身写成超教师或比复制更有效。

平均收益伴随负迁移。普通 OPD 一轮相对 IL 的 M_minus=0.009333，三个种子在独立筛出的 1,165 个 IL 稳定高分场景中，分别有 2/5/5 个后续五次均值为零。NC 平均下降 0.002594，CI [-0.006441,-0.000422]，不能宣称安全非劣。Anchor 的主要退化幅度收益区间仍跨零，额外抗退化作用为 INCONCLUSIVE，不能用较低点估计宣布成功。

独立局部确认也已完成：主来源历史 OPD 状态上的有限候选选择增益为 0.000232，95% CI [0.000099,0.000459]；原生均值投影为 0.000132 [0.000053,0.000263]；guard 后为 0.000051 [0.000009,0.000150]。有小幅正效应，不能写成“零收益”。但区间上界远低于预注册的 0.002 实质性扩训门槛，当前投影/guard 变体的扩大训练路线为 NOT_SUPPORTED。停止该分支是依据足够窄的效应区间，而非仅因不显著；不启用额外确认增样，也不修改噪声、半径或目标。

## 模型、数值与信息边界

官方 IL/RL 使用同一冻结 VLM，原始特征为 2,800×1,536；基础规划器维度 384、small DiT、8×3 轨迹，完整动作是 0.5–4.0 秒的联合规划，不拆成环境 RL 时间步。IL/RL 动作头结构、归一化及五步时间序列相同，实际参数不同。RL 教师来自经过 RL 优化的 active action_head，未误用 old_policy；RL 的 old_policy 与 IL 参考对应。347 个核心张量严格加载，六个明确不参与基础前向的辅助参数单列，没有随机初始化正式模型。

推理保持原生随机 DDIM5。代码实际 sigma 约为 [0.73775,0.51397,0.29511,0.02506,0.0001]，噪声裁剪 ±1，最后一步 latent clamp ±1；配置名 ddim_eta=0 并不等于此执行路径无随机方差。所有蒸馏目标在原始归一化空间计算，未修改 norm_odo/denorm_odo 或航向编码。

正式评价的规划器使用 B1、FP32、TF32 关闭、相同观察和语义初始噪声；共享 VLM 保持官方 BF16 编码。完整 RL/COPY 的 1,696×5 轨迹与分数逐元素相同；完整 E0 原生/CUDA graph 数值也一致。B8/B32 完整推理曾超过 1e-6 分数容差，因此没有用于正式结果。后缀批处理另外经过独立真实检查，不借此放行未通过的完整推理批处理。

VLM 缓存来自实际可见的历史图像、指令及自车状态，使用动作生成的同一输入路径，不含答案 token、GT 轨迹或真实未来。没有新动作头、特征对齐、最终轨迹伪 GT、专家条件分支或推理选轨。三个锁定学生已从真实图像重新编码并在隔离进程独立部署：在线 token 和五个噪声下的原生输出均与训练侧一致；禁止教师、评分缓存、未来标签及过程模块访问。

## 方法与源码复用边界

普通 OPD 每次更新以当前学生重新产生 detached 去噪链，教师在相同状态上提供冻结转移均值，学生重新前向计算 MSE 并更新整个原生动作规划器。梯度不穿过整条采样链。这里是 generation-level on-policy；NAVSIM 固定日志不构成持续环境交互。

过程方法在当前状态下由固定 T0 原生核采样有限候选，以 fit 续采样的真实 PDMS 构造 soft 权重，再以中心化权重差投影为转移均值位移。ESS、按实际 sigma 标准化的 RMS 半径及原始 clamp 均保留；sigma 为零不人为增加噪声。独立 guard 需 PDMS 均值改善且 NC/DAC/TTC 无下降，否则精确回到普通教师 OPD。诊断 test 使用另一噪声命名空间，不能回流目标或选参。

有限候选加权分布、投影后的原生随机核、guard 后核及最终学生是四个不同对象。本实现不把 MSE 称为确定性核之间的有限 Gaussian KL，也不把受裁剪核的有限样本投影称为精确 MPO/KL 解。DiffusionOPD、VIDD、SVDD、MPO、DPPO 的具体阅读文件、版本和数学适配范围见 `docs/RECOGDRIVE_PROCESS_SOURCE_REUSE.md` 与 `configs/process_improvement/references.lock.json`；不是跨领域原论文的机械复现。

原生 GRPO 保留 group8、原 advantage、原 diffusion logprob 近似、原单一 IL BC 约束及原采样流程。训练主比较将实际 PDM 权重统一为标准 PDMS 的 5/5/2；原 10/5/2 口径另外标注。原 clipped-Gaussian logprob 是既有 surrogate，不宣称裁剪核的精确密度；没有叠加等价 Anchor，也没有共享其他组的动作充作 on-policy 数据。

## 数据、统计与已有结果

完整合法 navtrain 总体是 103,288 个场景，未以缓存缺失剔除。训练 74,885 场景/903 log/127 父记录；cal 共 16,005 场景，按父记录分为 tune/confirm/promotion；锁定 dev 为 1,696 场景/16 log/15 父记录。dev 同父记录的其他片段保持保留，不冒充无效数据。底模可能已经见过官方训练数据，所谓保留仅针对本轮新增训练。

主分析先按每个训练策略在场景内平均五个推理种子，再分别截取正/负变化计算 M_plus/M_minus，最后平均独立训练策略。父驾驶记录是主聚类单位，完整 log 为敏感性分析；训练策略和全局配对噪声 ID 保留交叉层级。五个推理种子不当作五次训练，多个学生不混成不存在的集成模型。所有主要区间 10,000 bootstrap，罕见事件及少量父记录的结论明确保留不确定性。

真实基线、三种子 OPD/Anchor、直接归因及高分失败表见 `04_baseline_results.md`；固定曝光/覆盖诊断见 `06_expanded_training.md`。相同 64,000 次曝光下，4k/25k/full 的 seed42 dev PDMS 为 0.941485/0.945113/0.944951，不能据此宣称覆盖单调有效。完整训练两轮没有稳定超过一轮，cal 规则未允许扩到四轮；四轮为 NOT_RUN，没有继续加资源寻求正结果。

校正后的局部网格和探索历史在 `05_local_diagnostics.md`。早期 token-hash 子集不满足父记录哈希要求，保留为探索；正式子集在未观察任何确认标签时重建并锁定，只有完全相同输入的 51 个重叠标签复用。旧、新选择文件分开，不把探索结果写成独立确认。

案例图依据固定数值规则选修复、退化及迁移失败，展示实际地图、计划/跟踪轨迹和事件时刻，见 `figures/cases/`。对象未来占用仅作 privileged 图示，不进入策略；首次 TTC 检查失败时刻不是真实剩余碰撞时间。成功与失败案例、零分输出及未运行端点均保留。
