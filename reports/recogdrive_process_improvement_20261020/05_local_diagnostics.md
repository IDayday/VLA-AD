# 局部机制诊断：保留探索结果，纠正后的独立确认执行中

早期诊断的场景选择没有满足规范第 16 节的父记录哈希要求。下表来自保留的 token 哈希子集，只用于透明展示已运行结果，不能替代纠正采样后的 H2/H3 主确认。所有轨迹均真实调用公开检查点和 NAVSIM 跟踪评分，没有生成虚拟分数。

历史 OPD roll-in、价值加权温度 0.02、rho=0.5，M=16、fit=8、guard=8、独立 test=16、两个候选库、全部五个去噪位置：

| 探索子集 | 价值选择收益 | 投影均值核收益 | guard 后均值核收益 |
|---|---:|---:|---:|
| 512 train / 113 父记录 | 0.000814 [0.000238,0.001637] | 0.000210 [0.000006,0.000530] | 0.000095 [0.000006,0.000333] |
| 512 cal-tune / 7 父记录 | 0.001870 [0.000614,0.003712] | 0.000544 [0.000174,0.001143] | 0.000233 [0.000019,0.000585] |

方括号为保留父记录、候选库及配对后续噪声层级的 95% bootstrap 区间；条件是固定 roll-in seed。这里的温度不是原生 DDIM eta。选择收益评价的是有限候选分布，投影收益评价的是原生噪声核中的均值位移；两者不能互相替代。最终学生目前也不能用这些目标程序分数代替评价。

局部 P0 指给定 roll-in 前缀和当前数值状态后的原参考转移/续采样，并不是 T0 从初始噪声生成整条轨迹的部署成绩。P1 使用 fit 权重乘独立 test 候选回报，P0/P2 使用新当前步噪声且严格配对。最后一步的候选后续没有随机步骤，重复位置不是新的独立 suffix 样本；P0/P2 当前步核仍按真实噪声评价。局部条件均值不能与完整模型 PDMS 直接相减来宣称学生已实现过程收益。

这些探索实验共执行 10,604,357 次物理候选评分、23,592,960 次逻辑请求，单 GPU 作业累计约 34.88 GPU 小时。此成本属于真实研究开销，纠正采样后不会被删除或隐藏。原始数据保留在 `diagnostics/local_train_grid`、`local_cal_grid`，并有 `sampling_role.json` 标明非主确认用途。

早期还真实执行了 16 场景的动态教学程序小测（默认 M8/fit2/guard2）：80 个目标全部被 guard 拒绝，完整链相对参考的平均增益为零，共 1,416 次物理评分、1,632 次逻辑请求。该结果保留在 `tables/dynamic_teaching_exploratory.json` 和原 `diagnostics/dynamic_teaching/`；它验证了动态回退路径，不能证明接受目标的效果。纠正后的固定 16 场景、锁定配方 M16/fit8/guard8 动态诊断已单独排队，不覆盖旧结果；各步在新访问状态重算目标，不把静态目标拼成程序。

正式纠正只改变诊断抽样规则：按父记录哈希排序轮询，再按固定的记录内哈希取场景，不依据得分过滤。train/cal-tune/cal-confirm 各 512 场景，父记录数分别为 127/7/7；训练总体、评分、三种 roll-in、六个温度/rho 组合、M/L、阈值和一次预登记确认扩容规则均未改变。新子集与全部哈希在 `configs/process_improvement/diagnostic_sampling_correction.json`；旧选择文件保留，正式选择将写入独立的 `process_hyperparameters_parenthash.json`。

当前 H2/H3 为 `INCONCLUSIVE`，等待正确子集的诊断、cal-tune 选择及独立 cal-confirm 确认。不能因为旧探索结果的投影较小就跳过纠正后的实验，也不能据此暂停普通 OPD、Anchor 或原生 GRPO。

## 完成的动态程序与当前学生 suffix 诊断

锁定配方下的 16 场景动态程序也已真实完成。每一步访问新状态后重算目标，但 80 个目标全部被 guard 拒绝，动态链与原参考的平均 PDMS 均为 0.976740，增益为零。另行冻结评价的一轮 OPD seed42 在这 16 个 D_fit 场景为 0.976404；没有使用过程目标更新它，因此这个数值不能证明学生已经继承过程改进。实耗 9,392 次物理评分、11,568 次逻辑请求，参考 DiT 560 次调用/23,280 个轨迹状态，冻结学生 80 次/80 状态。`tables/dynamic_parent_teaching.json` 保留所有结果，旧零增益小测没有被覆盖。

当前完整 OPD 学生的 suffix mismatch 也完成了 128 个固定 cal-confirm 场景、7 个父记录的真实诊断。使用主训练大小的 M8/fit2/guard2，一共 640 个目标、5 个接受；目标和当前步参考核固定，只替换后续策略，测试噪声严格配对。加入保存的 16 组 test 噪声轴后，参考 suffix 的增益为 0.000060，95% CI [0.000004,0.000253]；学生 suffix 为 0.000096，CI [0.000005,0.000382]；二者差为 +0.000036，CI [-0.000124,0.000321]。这里未发现明确的额外 suffix 损失，也没有达到实质性收益门槛。
